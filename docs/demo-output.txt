**URL and Slug Style Guide** [doc:style-guide]
- Slugs are lowercase ASCII only. Accented characters are transliterated to their closest ASCII letter (é becomes e, ü becomes u) and any other non-ASCII character is dropped. [doc:style-guide]
- Words are separated by a single hyphen. Runs of spaces, underscores or punctuation collapse into one hyphen, and a slug never contains two hyphens in a row. [doc:style-guide]
- Slugs never start or end with a hyphen. [doc:style-guide]
- Slugs are at most 60 characters. When truncating, cut at the last hyphen boundary so no word is split. [doc:style-guide]
- An input that produces an empty slug (for example only punctuation) must return the fallback slug "untitled". [doc:style-guide]

**Python Engineering Standards** [doc:python-standards]
All production Python must include type hints on public functions and a docstring that states behaviour, not implementation. [doc:python-standards]

```python file=solution.py
import re
import unicodedata


def slugify(text, max_length=60):
    """Turn a title into a URL slug, following our style guide."""
    # turn accented letters into plain ones (é -> e) and drop anything else that isn't ASCII
    text = unicodedata.normalize("NFKD", text).encode("ascii", "ignore").decode("ascii").lower()
    # anything that isn't a letter or digit becomes a single hyphen
    slug = re.sub(r"[^a-z0-9]+", "-", text).strip("-")
    if len(slug) > max_length:
        # cut at the last hyphen that fits, so no word gets chopped in half
        cut_here = slug[:max_length + 1].rfind("-")
        slug = slug[:cut_here] if cut_here > 0 else slug[:max_length]
    return slug or "untitled"
```
